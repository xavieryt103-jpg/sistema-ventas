# Sistema de Ventas

Sistema de ventas para una MYPE: clientes, productos, ventas con IGV y reporte diario.

## Requisitos
- Node.js 18 o superior

## Instalacion
git clone https://github.com/xavieryt103-jpg/sistema-ventas.git
cd sistema-ventas

## Uso
npm start

## Pruebas
npm test

## Flujo de ramas
main (produccion) <- release/* <- develop <- feature/*, fix/*
hotfix/* sale de main y vuelve a main y develop.
