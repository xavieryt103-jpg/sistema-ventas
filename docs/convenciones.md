# Convenciones del equipo

## Ramas
- feature/nombre: funcionalidad nueva (sale de develop)
- fix/nombre: correccion en desarrollo (sale de develop)
- release/x.y: preparar una version (sale de develop)
- hotfix/nombre: error urgente en produccion (sale de main)

## Commits
- feat: funcionalidad nueva
- fix: correccion
- docs: documentacion
- test: pruebas
- chore: configuracion

## Versiones
- x.y.Z: correccion
- x.Y.0: funcionalidad nueva
- X.0.0: cambio grande
